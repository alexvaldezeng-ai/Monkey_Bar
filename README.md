# Monkey_Bar
The mission of Monkey Bar is to launch, land, and aim a rocket. We plan to develop three system to do this.
  Guided Rocket 
    Guided rocket will come in two stage, bottom stage (Booster) with two Thrust Vector Control mounts to land the booster and top stage (Dart) will aim onto a goal in which we measure accuracy over speed to have a presentable yield. Dart will also have Canard Fins in order to improve its accuracy. 
  Ground Station
Ground Station promises on board safety of the Monkey Bar Rocket by live transmitted data by Yagi Antenna. 
  Launch System
Launch system ensure reliable launch, landing, and aiming of the rocket. This system provides a clean landing site for the Booster and safe site to measure Dart's yield.
